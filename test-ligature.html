🎵 Omenaad Fonts - SS Ligature Test

How It Works

Ligature Rule: When you type the tilde character ~, it displays as two overlapping S characters (smaller in size).

The actual text contains ~ but the font renders it as ⓢⓢ (two smaller S's with overlap).
What You Type What You See Font File Property
~ (tilde) SS (two overlapping S characters, 75% size) S_S_small_overlap glyph
Normal text stays normal Normal text Ligature only affects ~

Technical Details

Glyph Composition

The S_S_small_overlap glyph is created by compositing two scaled S components:

  • First S: 75% scale, positioned at x=0, y=0
  • Second S: 75% scale, positioned at x=700, y=0
  • Total width: 1800 units (creates ~32% overlap)

Feature File Rule

feature liga {
    sub asciitilde by S_S_small_overlap;
} liga;
